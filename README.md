Entry for the [Make Fun bounty "The GPS Swears It Was a Shortcut"](https://make.fun/c/u-alven-the-gps-swears-it-was-a-shortcut-2cac21d9): write the GPS's one-line excuse for sending the driver down the wrong road.

## The entry

> I followed the map to the letter — if it meant a road and not a stranger's wedding in a cul-de-sac by the lake, it should have said so.

## Run

```sh
python3 main.py
```

`main.py` (pure stdlib, deterministic) writes the single-line excuse to `/output/entry.txt` and prints it. The line is 135 characters, one line of plain UTF-8 text.
